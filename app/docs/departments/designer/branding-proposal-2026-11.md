## 1. 앱 이름 — "취향 아카이브"로 바꾼다

| 안 | 한국어 | 영어 | 런처(커버 화면) | 평가 |
| --- | --- | --- | --- | --- |
| 현행 | 테이스트 아카이브 | Taste Archive | ❌ "테이스트 아…"로 잘림 | 이미 확정된 이름이지만 앱 서랍에서 이름이 읽히지 않는다 |
| **A (권장)** | **취향 아카이브** | Taste Archive | ✅ 전부 보임 (실기기 확인) | 아래 참고 |
| B | 테이스트 아카이브 (런처 라벨만 "취향 아카이브") | Taste Archive | ✅ | 브랜드와 런처 이름이 달라 두 이름을 갖게 된다 |
| C | 새 이름 (예: 잔기록) | — | ✅ | 확정된 이름을 버릴 근거가 약하다. 기능 직관성도 A보다 낫지 않다 |

**A를 권하는 이유**

- **번역이지 음역이 아니다.** "Taste"에는 "취향"이라는 자연스러운 우리말이 있다. 음역한 "테이스트"는
  입문자에게 뜻이 바로 오지 않고 9자로 길다. "아카이브"는 우리말 대안("기록 보관소")이 더 어색하므로
  외래어를 유지한다. 이것이 5절 표기 원칙 R2를 이름에 적용한 결과다.
- **앱 안의 말과 이어진다.** 앱은 이미 "취향 유형", "취향 카드", "내 취향"을 쓴다. 이름과 화면 어휘가 한 줄로 묶인다.
- **영어 이름은 그대로다.** 공유 카드 서명 "Taste Archive"와 스토어 영문명은 바뀌지 않는다.
- **비용이 지금 가장 낮다.** 게시 이력이 없다(`branding.md` 1절). 바꾸는 곳은 `app_name`과 화면 문자열 몇 곳뿐이다.

> 상표·스토어 중복 조회는 하지 않았다. Play Console 등록 전에 필요하다(기존 `branding.md` 1절과 같은 조건).

## 2. 아이콘 — 반반 잔 유지

교체한 지 하루 된 아이콘이고, 핵심 가치를 그대로 말한다.

- **와인과 위스키를 한 잔에** 담았다 = "두 술을 한 취향 언어로 묶는다"(PRD 4절의 핵심 주장).
- 두 반쪽의 무게가 같다 = 주종에 우열이 없다.
- 글자·사진 없음, 48px에서 두 잔이 구분된다(실기기 확인).

**보정할 것** (형태는 그대로):

1. 모티프가 마스크 대비 조금 작고 왼쪽 위로 쏠려 보인다. 시각 중심을 맞춘다.
2. 테마(모노크롬) 아이콘을 실기기에서 아직 확인하지 않았다.

## 3. 핵심 가치 — 문장은 유지, 판단 기준을 붙인다

> **한 잔의 기록이, 당신의 취향을 만듭니다.** / *Every glass shapes your taste.*

문장은 좋다(`branding.md` 4-1절). 문제는 화면 문구를 쓸 때 이 문장으로 옳고 그름을 가를 수 없다는 점이다.
그래서 문장을 **판단 기준 3개**로 풀어, 모든 화면 문구를 이것으로 검사한다.

| 기준 | 뜻 | 문구가 이를 어기는 예 |
| --- | --- | --- |
| **V1. 가볍게 남긴다** | 입력은 몇 번의 탭. 무엇이 필요한지 묻기 전에 말해 준다 | 저장 버튼이 이유 없이 꺼져 있음 |
| **V2. 내 말로 돌려받는다** | 결과는 전문용어·분석 용어 없이, 사용자가 남긴 말 그대로 | "축", "지표", "1080×1920", "심플한" |
| **V3. 다음 한 병을 고른다** | 모든 출력은 매장에서 쓸 수 있어야 한다. 근거는 "내 기록" | 근거 없이 같은 문구만 반복하는 추천 이유 |

## 4. 취향 유형 명명

### 4-1. 유지하는 것

- **4글자 코드와 글자 배정.** `S/D`(단맛) · `F/L`(무게감) · `R/M`(향의 세기) · `E/Q`(여운) · `X`(가리지 않음).
  공유 카드와 사용자의 정체성이 이 코드에 묶여 있다. 글자를 바꾸면 이미 본 유형이 달라진다.
- **축 순서 고정, 코드와 이름은 항상 함께, 우열·희귀도 표시 금지**(`taste-type-naming.md` 2·4절).
- **"MBTI", "성격유형검사"라는 말은 화면에 쓰지 않는다**(`branding.md` 4-5절). 형식만 빌린다.

### 4-2. 고치는 것

| # | 문제 | 지금 | 제안 |
| --- | --- | --- | --- |
| N1 | 짧은 이름의 문법 | "드라이한 묵직한 취향" | **"드라이하고 묵직한 취향"** — 앞 형용사는 연결형(-하고)으로 |
| N2 | 여운의 짧은 쪽이 산미와 같은 말 | 여운 "산뜻함" / 산미 "산뜻함" | 여운의 짧은 쪽을 **"깔끔함"**(깔끔하게 끝나요)으로. 산미는 "산뜻함" 유지 |
| N3 | 코드 글자를 한국어로 되짚을 수 없음 | "F · 묵직함" — F가 왜 F인지 알 수 없다 | 유형 화면에 **글자 해설 한 줄**: `D Dry 드라이 · F Full 묵직 · R Rich 진함 · E Enduring 긴 여운`. 영어는 여기서만 쓴다(R3) |
| N4 | 같은 유형을 부르는 말이 여러 개 | "취향 유형", "취향 유형 코드", "4글자 취향 유형", "MBTI형 코드"(제거됨) | **"취향 유형"** 하나. 코드를 따로 가리킬 땐 "유형 코드" |

### 4-3. 이름 조립 규칙 (N1·N2 반영)

```text
짧은 이름 = 방향이 있는 축 중 앞선 2개를 축 순서대로, "A하고 B한 취향"
           방향이 하나면 "A한 취향", 전부 가리지 않으면 "고루 즐기는 취향"
예) DFRE → 드라이하고 묵직한 취향
    XFXQ → 묵직하고 깔끔한 취향
    SXXX → 달콤한 취향
```

## 5. 한글/영어 표기 원칙

### 원칙

| # | 원칙 | 적용 |
| --- | --- | --- |
| **R1** | **화면 언어는 한국어다.** 영어는 브랜드 워드마크(공유 카드 서명), 유형 코드, 코드 해설에만 쓴다 | 접근성 문구(스크린리더용 설명)도 한국어 |
| **R2** | **우리말에 자연스러운 말이 있으면 우리말, 없거나 매장·라벨에서 그 말을 쓰면 외래어 한글 표기.** | 취향(O)/테이스트(X), 심플한(X)/간단한(O). 아카이브·드라이·싱글몰트·버번·캐스크·피트·하이볼·니트·빈티지는 외래어 유지 |
| **R3** | **한국어 문장 안에 영어 단어를 섞지 않는다.** 알파벳은 코드 글자와 단위(%)에만 | "dry한"(X), "Dry 와인"(X) → "드라이 와인" |
| **R4** | **한 개념에는 한 이름.** 아래 용어집이 기준이고, 화면 문구는 용어집에서만 고른다 | P2 #7·#10·#11 |
| **R5** | **감각은 우리말, 분류는 매장 말.** 맛을 묘사할 때는 고유어(달콤·묵직·은은·깔끔), 술을 분류할 때는 라벨 용어(싱글몰트·셰리 캐스크) | 위스키 피트 축: "논피트 ↔ 스모키함" → **"스모키하지 않음 ↔ 스모키함"** (분류어 "피트"는 태그에만) |

> **질문에 대한 답**
> - **아카이브 or Archive** → 한국어 화면과 앱 이름은 **"아카이브"**(R1·R2). 영어는 공유 카드 서명 "Taste Archive"에만.
> - **드라이 or dry** → **"드라이"**(R2·R3). 라벨과 매장에서 "드라이 와인"이라고 쓰므로 외래어가 맞다.
>   "단맛 없음" 같은 우리말은 매장에서 쓰는 말과 이어지지 않는다(V3). 코드 글자 `D`의 해설에서만 "Dry"를 쓴다.

### 용어집

| 개념 | 쓴다 | 쓰지 않는다 |
| --- | --- | --- |
| 앱 이름 | 취향 아카이브 / Taste Archive | 테이스트 아카이브, 테이스트 Archive |
| 기록 하나 | 기록, 셀 때는 **잔** ("84잔") | 개, 병, 건 |
| 맛을 묻는 항목(Trait) | **맛 기준** ("6가지 맛 기준") | 축, 지표, 성향 |
| 취향 판정 결과 | 취향 유형 / 유형 코드 | 4글자 취향 유형, MBTI형 |
| 별점 | **별점**. 기록 하나는 0.5 단위 `4.5`, 평균은 소수 한 자리 `3.9`, 뒤에 "점" | `4 / 5`, `5 / 5`, 만족도와 혼용 |
| 다시 살 의향 | 또 살래요 · 그냥 그래요 · 안 맞아요 | 재구매, 다시 살래요, 무난해요 |
| 하단 탭 | **내 취향 · 아카이브 · 매장 찾기** + 기록하기(+) | 대시보드, 컬렉션, 검색 |
| 공유 이미지 | 취향 카드, "스토리에 올리기 좋은 세로 이미지" | 9:16, 1080×1920 |
| 백업 | 백업 파일 | JSON 파일 |

> **하단 탭 이름을 바꾸는 이유**: "대시보드"는 분석 도구의 말이라 V2에 어긋나고, 화면이 실제로 보여주는 것은
> 내 취향 유형이다. "컬렉션"은 수집가의 말이다(`branding.md` 2-1절이 폐기한 톤). "아카이브"로 바꾸면
> 앱 이름 "취향 아카이브"가 탭 두 개("내 취향" + "아카이브")로 그대로 풀린다.
> 탭 이름과 화면 제목은 같게 한다.
